# Mesh of a cylinder of diameter 200 and length 2000 with a mesh size of 5 (in nm)

The script is examples/curling/fg-mesh-cylinder. From examples/curling:

./fg-mesh-cylinder --diameter 200 --length 2000 --mesh_size 5 --version 4
generates the mesh cyl_D200_L2000_h5_fg.msh in the ASCII format, version 4.1
(the default format: --version 4 can be omitted).

To generate a mesh in the ASCII format, version 2.2, type
./fg-mesh-cylinder --diameter 200 --length 2000 --mesh_size 5 --version 2

To also write the name of the mesh file in a settings file (mesh: filename:), add
--settings settings.yml
Only this line of the settings file is modified, its comments are kept. The script also warns
about the regions of the settings file that are not physical groups of the mesh
(cyl_volume, inlet, outlet, side_surface).

Without any argument, the script prints its help.
Requires the gmsh Python module (pip install gmsh), and pyyaml with --settings
(pip install pyyaml).
